# IQUP Tracker — видение системы

> Учебный центр **IQ UP** (Бишкек, 3 мкр, 6 дом) — математика, подготовка к ОРТ, химия, продлёнка (1–8 класс).
> Владелица — Каныкей. Instagram: [@iqupkg](https://www.instagram.com/iqupkg/).

## 1. Проблема

Каждый день зарплаты учителя спорят с владелицей о расчёте. Причина — нет единого источника правды о том, **какие занятия реально прошли, сколько они длились и кто на них был**. Всё считается вручную задним числом, по памяти и переписке.

## 2. Цель системы (одно предложение)

**Фиксировать факт и время каждого проведённого занятия в момент его проведения, чтобы зарплата учителя считалась автоматически и бесспорно, а оплаты учеников были прозрачны.**

Критерий успеха: в день зарплаты владелица открывает отчёт по учителю за месяц, учитель открывает тот же отчёт у себя — цифры совпадают, и обсуждать нечего.

## 3. Принципы

| Принцип | Что это значит на практике |
|---|---|
| **Факт фиксируется в момент события** | Учитель отмечает посещаемость во время занятия, а не вечером и не в конце месяца. Система записывает время отметки. |
| **Ничего не удаляется, всё журналируется** | Любое изменение занятия/посещаемости/оплаты задним числом — отдельная запись с автором, временем и причиной. Спор решается просмотром истории. |
| **Закрытый период не меняется** | Бухгалтер «закрывает» месяц. После этого прошлые занятия и расчёт ЗП заморожены; корректировки — только отдельной строкой в следующем периоде. |
| **Учитель видит свою ЗП сам** | Прозрачность работает в обе стороны: учитель в любой момент видит отработанные часы и предварительную сумму. |
| **Правила — в настройках, не в коде** | Тарифы, ставки учителей, число допустимых пропусков — редактирует администратор без программиста. |
| **Бесплатно в эксплуатации** | Бесплатный хостинг, бесплатная БД, поддомен без покупки домена. Система для личного пользования одного центра. |

## 4. Роли

```mermaid
flowchart LR
    T[Учитель] -->|отмечает посещаемость,<br/>видит свои занятия и ЗП| S((IQUP Tracker))
    A[Администратор] -->|создаёт группы, учеников,<br/>расписание, тарифы, пользователей| S
    B[Бухгалтер] -->|смотрит всё, закрывает период,<br/>экспортирует расчёт ЗП| S
```

| Роль | Видит | Делает | Не может |
|---|---|---|---|
| **Учитель** | Свои группы, своё расписание, своих учеников (остаток уроков и долг с суммами), свои часы и предварительную ЗП | Отмечать посещаемость (присутствовал / заморозка / сгорел), подтверждать проведение занятия, создавать доп. урок для своей группы, оставлять комментарий | Видеть чужие группы, менять тарифы и проценты, править оплаты, менять прошлое после закрытия периода |
| **Администратор** (Каныкей и Алишка) | Всё | Всё, что учитель + CRUD групп, учеников, расписания, праздников, тарифов, процентов учителей, пользователей; абонементы, платежи, возвраты, авансы; правки задним числом (с причиной) | — |
| **Бухгалтер** | Всё | Закрывать/открывать расчётный период, вносить корректировки в расчёт | Создавать/редактировать пользователей, группы, учеников, тарифы, посещаемость, платежи |

Деньги от родителей принимает и записывает **администратор** (анкета Г1); бухгалтер проверяет и закрывает месяц.

## 5. Пользовательские сценарии

### 5.1 Учитель — рабочий день

```mermaid
sequenceDiagram
    actor T as Учитель
    participant App as IQUP Tracker (телефон)
    T->>App: Вход (телефон + пароль)
    App-->>T: «Сегодня»: список занятий по времени,<br/>текущее занятие подсвечено
    T->>App: Открывает занятие 15:00 «Математика 8 класс»
    App-->>T: Название, время, список учеников группы
    T->>App: Отмечает ✅ / ❌ по каждому ученику
    T->>App: «Провести занятие» (фиксируется время)
    App-->>T: Занятие «Проведено», часы добавлены в месяц
    T->>App: Вкладка «Мой месяц»
    App-->>T: Часы, занятия, предварительная ЗП
```

Детали поведения:
- По умолчанию открывается **сегодня**. Если текущее время попадает в окно занятия (15 минут до и 30 после), занятие показывается первым и крупно — одна кнопка «Открыть». Заходить ровно во время урока не обязательно — можно отметить позже в тот же день по памяти.
- По каждому ученику три кнопки: **Был** / **Заморозка** (предупредил заранее, лимит 2 на абонемент) / **Не был** (урок сгорает). Система подсказывает, сколько заморозок у ученика осталось.
- Если учитель не отметил занятие в тот же день, оно висит как **«Не подтверждено»** у учителя и у админа. Учитель может подтвердить сам до закрытия месяца — с пометкой «поздно». В ЗП не попадает, пока не подтверждено.
- Замена учителя: отмечается для истории, деньги остаются у основного учителя группы (взаимозамена без перерасчёта).
- Отменённое занятие учитель восполняет **доп. уроком** — создаёт его из экрана группы, оно появляется в расписании и оплачивается как обычное.

### 5.2 Администратор — запуск группы

1. Создаёт группу: название, предмет, класс, тип (групповая / мини / парная / индивидуальная / продлёнка), учитель, расписание (дни недели + время + длительность), дата старта.
2. Система генерирует занятия на N недель вперёд (например, до конца учебного года), пропуская праздники из календаря.
3. Добавляет учеников в группу (зачисление) — с датой начала. Ученик, пришедший в середине курса, видит занятия только с даты зачисления.
4. Назначает тариф группе и ставку учителю.

### 5.3 Бухгалтер — день зарплаты

1. Открывает «Расчёт ЗП» за месяц → таблица по учителям: проведено занятий, часов, ученико-уроков, процент, сумма, авансы, итог к выплате 15-го.
2. По каждой строке можно провалиться до занятий → до учеников: «за Айжан начислено 6 × 120 = 720 сом».
3. В пилотный месяц рядом показана сумма по старой схеме (45 % от оплат месяца) — чтобы объяснить расхождение.
4. Нажимает «Закрыть период» — расчёт замораживается.
5. Отдельный экран «Деньги за месяц»: оплаты по группам и учителям, наличные / Mbank, у кого долг.

## 6. Что система НЕ делает (пока)

- Не принимает платежи онлайн, не интегрируется с банками.
- Не ведёт журнал оценок и домашних заданий.
- Не отправляет SMS/уведомления родителям (может позже — Telegram-бот). Родительского кабинета нет.
- Не фиксирует фактическое время начала/конца занятия — только факт проведения.
- Не экспортирует в Excel/PDF — Каныкей достаточно экрана.
- Не считает налоги и не формирует официальные бухгалтерские документы.
