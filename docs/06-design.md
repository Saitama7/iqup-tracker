## Состав экранов (36)

Пробные занятия (добавлены 08.10 по отзыву Каныкей) показаны на: У2 (бейдж на текущем + блок «Завтра»), У3 и УД2 (секция «Пробные» с кнопками Был / Не пришёл), А1 (виджет), А2 (легенда, чипы в ячейках, пунктирная ячейка группы на наборе), А4 (секция в таблице + «На пробное»), А11 (отдельный экран).

### Диалоги и состояния (добавлены 09.10 по комментариям Кайрата)

Это не отдельные маршруты, а модальные окна и выезжающие панели поверх экранов выше. В коде — `Dialog` / `Sheet` из shadcn.

| Артборд | Открывается с | Что показывает и как работает |
|---|---|---|
| Б1а Архив периодов | Б1, клик по названию месяца (или стрелки ‹ ›) | Сетка 12 месяцев года с суммой и статусом (закрыт / открыт / идёт / будущий), переключение года, строка прошлых лет, «Экспорт года в Excel». Закрытый месяц открывается только для чтения |
| Б1б Закрыть период | Б1, «Закрыть период» | Чек-лист (все занятия подтверждены, авансы внесены, тариф не менялся, предупреждение — не блокирует), итог, что произойдёт (занятия блокируются, суммы замораживаются, правки только корректировкой, переоткрыть может только админ), комментарий, запись в журнал |
| Б1в Сверка со старой схемой | Б1, «Сверка со старой схемой» | Панель справа: новая схема vs 45 % от оплат месяца по каждому учителю, разница и причина (деньги переехали между месяцами или скидки). Нужна первые 2–3 месяца, чтобы объяснять учителям разницу. «Скачать XLSX» |
| Б2а Корректировка | Б2, «+ Корректировка» | Тип (аванс / премия / удержание / исправление), сумма, дата, причина (обязательно), кто выдал; предпросмотр «к выплате» до и после. «Исправление» — единственный способ изменить сумму после закрытия. Учитель видит строку сразу, запись в журнал |
| Б2б Расчётный лист | Б2, «Печать расчётного листа» | Предпросмотр A4: учитель, период, таблица по группам (занятий, ученико-уроков, цена урока, стоимость, %), корректировки, к выплате, подписи. Печать / PDF / WhatsApp; опции: список занятий (стр. 2), сверка, подписи. Генерируется в браузере. Учитель может скачать тот же PDF из «Моего месяца» после закрытия |
| А9а История тарифов | А9, «История тарифов» | Таймлайн версий тарифа с датой `valid_from`, кто и когда изменил, таблица было → стало с ценой урока, сколько абонементов ещё дорабатывается по старому тарифу. «Запланировать новый тариф с даты…» |

Правки по тем же комментариям: бейджи статусов и телефоны никогда не переносятся (`white-space: nowrap`), на плотных таблицах (А4, А6, А7, А8, А11, УД3) телефон-логин ушёл второй строкой под имя; А1 — виджет «Не подтверждено» показывает 3 свежих + «ещё N → расписание с фильтром»; А11 — групповая запись на пробное свёрнута до «N учеников», список раскрывается строкой под записью; У2 — в колоде только непроведённые занятия сегодня, под колодой индикатор «1 из N» и подсказка про свайп, в полоске задней карточки видно следующее занятие.

## Правила переноса макета в код

- Планшет = десктопный экран: боковое меню остаётся на ≥ 900 px, ниже складывается в верхнюю панель; таблицы — `overflow-x: auto`.
- Телефонные экраны и десктопные — один маршрут, разные layout-компоненты (`MobileShell` / `DesktopShell`), выбор по `matchMedia`.
- Все цвета — токены из §3 архитектуры, не hex в компонентах.
- Статусы всегда цвет + текст/иконка.
- Тестовые данные в макете (Гульзат, 8 класс А, Айжан Б. и т.д.) — переносятся в `supabase/seed.sql` как dev-сид.
