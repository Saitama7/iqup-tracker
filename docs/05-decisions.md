## А. Зарплата учителя

| # | Решение | Статус |
|---|---|---|
| А1 | **Формула:** за каждого учтённого ученика на каждом проведённом занятии учитель получает `процент_учителя × (package_price / lessons_in_package)` по тарифу группы. Считается только по занятиям, **проведённым в расчётном месяце** — не по оплатам. Пример: ученик записался 15 сентября → к 1 октября учителю начислено только за 6–7 сентябрьских уроков. | ✅ |
| А1.1 | База расчёта — **полная тарифная цена** урока. Скидки и акции на ЗП не влияют (за счёт центра). | ✅ (WhatsApp 07.10) |
| А1.2 | **Старая схема (для сверки в пилоте):** столбик оплат за месяц × 45 %, выплата 15-го. Система должна уметь показать обе цифры в пилотном месяце, чтобы объяснить расхождение. | ✅ |
| А1.3 | Учтённый ученик = тот, у кого урок **списался с абонемента**: присутствовал **или пропустил без предупреждения (урок сгорел — учителю начисляется)**. Замороженный урок учителю не начисляется. | ✅ (WhatsApp 08.10) |
| А2 | Процент — атрибут **учителя**: 45 % у всех, 50 % у одной учительницы (работает с открытия). От предмета/типа группы не зависит. | ✅ |
| А3 | Занятие — **60 минут**, одинаково для всех предметов и классов. Продлёнка — 3 часа. «Часы» учителя = 1 ч за занятие, 3 ч за день продлёнки. | ✅ |
| А4 | Природа споров: количество занятий («было/не было»), размер ставки, неучтённые замены/переносы. Длительность — не предмет споров → фактическое время (`actual_start/end`) в MVP не фиксируем. | ✅ |
| А5 | Никто не пришёл, учитель был → **платят полностью**: занятие `held`, посещаемость отмечается как обычно (неуважительные пропуски списываются и начисляются учителю). | ✅ |
| А5.1 | Если **вся группа** предупредила заранее — урок заморожен целиком: занятие `cancelled` (`all_frozen`), **переносится в конец месяца** доп. уроком, учителю за отменённое не начисляется (начислится за доп. урок). Групповая заморозка не тратит личный лимит заморозок учеников 🟡. | ✅ (WhatsApp 08.10) |
| А6 | Отменил центр (праздник, нет света) → **не платим**. Отменил учитель → **не платим**, без штрафа. Отменённые уроки **обязательно восполняются** доп. занятием (оплачивается при проведении). | ✅ |
| А7 | Замены бывают: **взаимозамена без перерасчёта** — начисление всегда основному учителю группы. Поле «фактически вёл» — информационное, в ЗП не влияет. | ✅ |
| А8 | **Авансы** — в любое время по просьбе учителя (вычитаются из выплаты). Премии пока нет, возможны позже. Штрафов нет. | ✅ |
| А9 | День выплаты — **15-е число**. Период — **календарный месяц** (сентябрь → выплата 15 октября). | ✅ |
| А10 | Учитель видит в «Моём месяце» **и часы, и сумму**. | ✅ |

## Б. Занятия и посещаемость

| # | Решение | Статус |
|---|---|---|
| Б1 | Отметить занятие можно **в течение дня занятия** (с начала занятия до 23:59), не обязательно во время урока. | ✅ |
| Б2 | Забыл отметить → учитель **сам** может подтвердить позже, **до конца месяца** (до закрытия периода). Позднее подтверждение помечается и видно админу. | ✅ |
| Б3 | Переносы **редко**. Отменённое занятие восполняется: учитель собирает учеников в свободное время или ставит **один доп. урок в конце месяца**. Моделируем как `lesson.is_extra = true` со ссылкой на отменённое. | ✅ |
| Б4 | Праздники — **свой список** центра (таблица `holidays`, ведёт админ). | ✅ |
| Б5 | Продлёнка: пришёл на 1 час из 3 → **присутствовал**, день засчитан; учителю — 3 часа по плану. | ✅ |
| Б6 | Масштаб: **10 учителей, ~100 учеников**, группы ещё формируются («каждый день появляются и исчезают»). Расписание — как в Instagram. | ✅ |

## В. Тарифы, абонементы, пропуски

| # | Решение | Статус |
|---|---|---|
| В1 | Абонемент = **12 занятий** (продлёнка — 20). Можно **заморозить 2** урока, остальные пропуски сгорают. Календарного срока нет. | ✅ |
| В2 | Уважительная причина = ученик **предупредил за день или минимум за 2 часа** до урока. Решает **учитель при отметке** или **администратор**. Лимит заморозки — **2 на абонемент**. Если заболел учитель — все уроки восполняются (это отмена, не заморозка). | ✅ |
| В3 | Отработка замороженных уроков — **дополнительное занятие** группы (не визит в чужую группу). | ✅ |
| В4 | Пришёл в середине абонемента группы → **полный абонемент**, свой отсчёт 12 занятий с даты зачисления. | ✅ |
| В5 | 15 % бывшим ученикам — **только первый абонемент**. 5 % «приведи друга» — **тому, кто привёл, на один абонемент**. Других скидок нет. | ✅ |
| В6 | Тарифы меняются **раз в год, в сентябре** → храним историю с `valid_from`. | ✅ |
| В7 | В долг — **да, максимум 3 занятия**. | ✅ |
| В7.1 | **Частичная оплата открывает пропорциональное число уроков.** Оплатил половину (1 600 из 3 200) → доступно 6 уроков; доплатил через неделю — открылись остальные. `оплачено_уроков = floor(Σ оплат / (price_final / lessons_total))`. Если ученик ходит сверх оплаченных уроков — это и есть «долг», допускается до 3 уроков (В7), система подсвечивает админу и учителю. Учителю начисляется за все списанные уроки, оплачены они или нет. | ✅ (WhatsApp 08.10) |
| В8 | Возвраты **бывают** → операция «возврат» (отрицательный платёж с причиной). **Сумма = остаток уроков × цена урока со скидкой** (`price_final / lessons_total`). | ✅ (WhatsApp 08.10) |

## Ж. Пробные занятия (комментарий Каныкей к макету, 08.10)

| # | Решение | Статус |
|---|---|---|
| Ж1 | **Пробные занятия есть.** Ещё не зачисленный ученик записывается на конкретное занятие группы; целая набираемая группа может быть «на пробном». В Excel Каныкей такие ученики — красным, с телефоном и датой; после оплаты — чёрным. | ✅ |
| Ж2 | Пробный урок **бесплатный**: не списывается, **учителю не начисляется**, в заполненность группы не входит. | ✅ |
| Ж3 | Учитель должен **видеть пробного заранее** («вечером зашёл — увидел, что завтра пробный») и отметить на занятии был / не пришёл. | ✅ |
| Ж4 | Цвет в системе — фиолетовый пунктир + подпись «пробный» (красный занят под «не подтверждено»). Легенда расписания дополнена. | ✅ |
| Ж5 | После оплаты админ нажимает «Оплатил → зачислить» — создаются зачисление и абонемент; абонемент начинается со следующего занятия. | 🟡 |
| Ж6 | Пробные **полностью бесплатные**: учителю не начисляется ничего, даже если на занятии были только пробные. | ✅ (WhatsApp 08.10) |
| Ж7 | Пробные приходят **и в активные группы**, не только в набираемые. | ✅ (WhatsApp 08.10) |
| Ж8 | **Не пришёл на пробное → админ звонит** узнать, ждать ли на следующий урок. В системе: статус `no_show` попадает в список «Позвонить» на экране пробных с телефоном родителя и кнопками «Записать заново / Закрыть». | ✅ (WhatsApp 08.10) |

## Следствия для модели (внесены в 01-domain-model.md)

- `PAY_RATE` упрощается до `TEACHER.pay_percent` (45 / 50) с историей `valid_from`.
- Новая сущность `SUBSCRIPTION` (абонемент): зачисление × тариф × скидка × 12 уроков; `PAYMENT` привязан к абонементу, может быть частичным и отрицательным (возврат).
- `ATTENDANCE.status` → `present | absent_frozen | absent_burned`; лимит заморозки 2 на абонемент.
- `LESSON.is_extra` + `makes_up_for_lesson_id` для доп. уроков; `LESSON.substitute_teacher_id` информационное; начисление по `GROUP.teacher_id`.
- `HOLIDAYS` — свой список.
- Старая схема (45 % от оплат месяца) — отдельный view для сверки в пилоте.
