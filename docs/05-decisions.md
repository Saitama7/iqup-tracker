| # | Решение | Статус | Источник |

| А1 | ЗП зависит от **числа учеников на проведённых занятиях**, не от количества занятий как таковых. Ученик, записавшийся 15-го, добавляет учителю оплату за 7–8 уроков этого месяца. ## Следствия для модели

- `PAY_RATE.rate_type` по умолчанию — `percent_of_revenue` (или `per_student_present`, если окажется фикс). Остальные типы остаются в модели, но не в приоритете.
- База расчёта — `TARIFF.package_price / TARIFF.lessons_in_package` на дату занятия, **не** `PAYMENT.amount`.
- `ENROLLMENT.discount_percent` влияет только на сумму оплаты ученика, не на ЗП.
- `ENROLLMENT.start_date` критичен для ЗП: ученик учитывается на занятиях только начиная с этой даты.
